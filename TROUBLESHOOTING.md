# 🔧 POCKETFORGE AI - Troubleshooting & FAQ Guide

Common issues encountered when developing on Android with Termux, and their verified solutions.

---

## 📱 Termux & Agent Issues

### 1. `Error: connect ECONNREFUSED 127.0.0.1:8765`
- **Cause:** The Termux local agent (`pocketforge-agent.js`) is not running.
- **Solution:**
  1. Switch to Termux on your phone.
  2. Run `node pocketforge-agent.js` or `pocketforge`.
  3. Ensure it outputs `Agent URL: http://127.0.0.1:8765` and `Status: ONLINE`.

### 2. `Invalid pairing token (HTTP 401)`
- **Cause:** The auth token entered in the PocketForge app does not match the token generated by the agent.
- **Solution:**
  1. In Termux, check `~/.pocketforge/token`:
     ```bash
     cat ~/.pocketforge/token
     ```
  2. Copy that exact string (e.g. `pf_sec_...`).
  3. In PocketForge Settings / Terminal, paste it into the **Auth Token** field and tap **"Pair Agent"**.

### 3. Termux stops running dev servers when switching apps
- **Cause:** Android OS aggressively optimizes battery by freezing background processes (Phantom Process Killer on Android 12+).
- **Solution:**
  1. Swipe down Android notifications and tap **"Acquire Wakelock"** on the Termux persistent notification.
  2. Go to phone **Settings** -> **Apps** -> **Termux** -> **Battery** -> select **"Unrestricted"**.
  3. On Android 12+, disable child process limits in Termux:
     ```bash
     /data/data/com.termux/files/usr/bin/bash -c "echo 'allow-external-apps = true' >> ~/.termux/termux.properties"
     ```

### 4. `pkg: command not found` or repository errors in Termux
- **Cause:** Installing Termux from Google Play Store instead of F-Droid.
- **Solution:**
  - Uninstall the Play Store version and install the modern APK from [F-Droid](https://f-droid.org/packages/com.termux/).
  - Then run `termux-change-repo` and select the main Grimler or Tsinghua mirror.

## 🌐 Web App & Preview Issues

### 1. "Localhost preview cannot connect to port 3000"
- **Solution:**
  - Ensure your server is listening on `0.0.0.0` or `127.0.0.1`.
  - For Vite apps, add `--host` to your script: `npm run dev -- --host`.
  - For Flask, use `app.run(host='127.0.0.1', port=5000)`.

### 2. Browser blocking mixed content or iframe loading
- **Solution:**
  - If you are opening PocketForge on `http://localhost:5173`, it can preview `http://localhost:*` servers without mixed-content restrictions.
  - If your phone browser blocks iframe embedding, tap the **"Open External Tab"** button in the Live Preview header to view the dev server directly in a separate browser tab!

## 🤖 AI Provider Issues

### 1. `Google Gemini 429: Resource has been exhausted`
- **Solution:**
  - Gemini free tier has per-minute request limits.
  - Turn on **"Enable Fallback"** in AI Settings and add a Groq API key (Groq provides free high-speed Llama 3.3 inference).
  - PocketForge will switch automatically when rate limits occur.

### 2. Groq `model not found`
- **Solution:**
  - Ensure you select `llama-3.3-70b-versatile` or `mixtral-8x7b-32768`.

## 🐧 Linux Mint Issues

### 1. `node_modules` missing after extracting ZIP on Linux Mint
- **Explanation:**
  - PocketForge intentionally excludes `node_modules` during export to protect your phone storage and avoid binary architecture mismatches between Android ARM64 and Linux x86_64.
- **Solution:**
  - Run `npm install` inside the project folder on Linux Mint.
  - Or simply run `./run-linux.sh`.
